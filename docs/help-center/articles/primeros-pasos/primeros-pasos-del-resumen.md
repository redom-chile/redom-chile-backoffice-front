"Primeros pasos" es una lista de tareas que aparece arriba en **Resumen**. Te muestra qué te falta para dejar tu restaurante listo para vender. Cada tarea se marca sola cuando la completas.

## Las tareas

| Tarea | Tipo | Te lleva a |
|---|---|---|
| Crea tu local | Esencial | Negocio → Sucursales |
| Carga tu carta (al menos un producto a la venta con precio) | Esencial | Carta → Productos |
| Toma tu primer pedido | Esencial | POS |
| Completa los datos fiscales (RUT del negocio) | Recomendado | Negocio → Mi negocio |
| Configura tus mesas | Opcional | Mesas |
| Invita a tu equipo (otro usuario además de ti) | Opcional | Roles y permisos → Usuarios |
| Conecta una impresora o una estación de cocina | Opcional | Configuración → Impresoras o Estaciones |

## Cómo usarla

1. Entra a **Resumen**. Verás la barra de avance ("3 de 7", por ejemplo).
2. La siguiente tarea pendiente aparece destacada, con un botón que te lleva a la pantalla correspondiente (por ejemplo, **Abrir el POS**). Las demás tienen una flecha.
3. Cuando completas la tarea y vuelves al Resumen, la lista se actualiza. También se actualiza cuando vuelves a la pestaña del navegador.

Cuando completas todas las tareas esenciales y recomendadas, la tarjeta se reduce a un aviso **¡Todo listo!**. Toca **Ver** si quieres abrirla otra vez.

## Ocultarla y volver a verla

- Toca **Ocultar** para quitar la lista del Resumen.
- Para recuperarla, toca **Ver primeros pasos**, junto al selector de período.

Ocultarla solo afecta al navegador que estás usando. En otro equipo, la lista vuelve a aparecer.

## Errores comunes

- **"No pudimos verificar tu avance."**: no se pudo consultar el estado y ninguna tarea se marca. Revisa tu conexión y toca **Reintentar**.
- **Una tarea aparece con un signo de pregunta**: no se pudo comprobar. Toca **Reintentar** o recarga la página.
