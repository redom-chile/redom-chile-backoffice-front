Los gastos que se repiten se crean en **Finanzas → Gastos recurrentes**. En cada fecha se generan solos como gastos pendientes en tus cuentas por pagar.

## Crear un gasto recurrente

1. Entra a **Finanzas → Gastos recurrentes** y toca **Nuevo recurrente**.
2. Completa **Descripción** (ej: *Arriendo local*), **Local**, **Categoría** y, si quieres, **Proveedor**.
3. Escribe el **Monto (con IVA)**, por ejemplo $800.000, y el **Documento**. Con factura se sugiere el **IVA (crédito fiscal)** y ves el neto.
4. Elige la **Frecuencia**: *Mensual* o *Semanal*.
5. Indica el **Día del mes** o el **Día de la semana**. En meses más cortos se usa el último día.
6. Elige el **Inicio** y, si quieres, el **Término**. Sin término, sigue hasta que lo pauses.
7. En **Días para pagar**, indica cuántos días después vence (0 = el mismo día, máx. 365).
8. Revisa el resumen (ej: *Cada mes el día 5*) y toca **Crear**.

Si el inicio es anterior a hoy, al guardar se crean como pendientes los gastos de las fechas que ya pasaron.

## Editar, pausar o reanudar

- Toca el lápiz para **Editar**. Los cambios aplican a los próximos gastos; los ya generados no cambian.
- Toca **Pausar** para detenerlo o **Reanudar** para seguir. Para ver los pausados, marca **Incluir pausados**.

## Categorías de gasto

Las categorías te ayudan a saber en qué se va la plata.

1. Entra a **Finanzas → Categorías de gasto**.
2. Toca **Nueva categoría**, escribe el **Nombre** (ej: *Publicidad*) y guarda.
3. Usa el lápiz para **Renombrar** una categoría, o toca **Desactivar** / **Activar**. Una categoría inactiva no se ofrece en gastos nuevos. Marca **Incluir inactivas** para verlas.

## Errores comunes

- **"La fecha de término no puede ser anterior al inicio"**: corrige las fechas.
- **"El IVA no puede ser mayor que el monto"**: ajusta el IVA.
- **"Ya existe una categoría con ese nombre."**: usa otro nombre o activa la existente.
- **"Ingresa el nombre de la categoría"**: el nombre es obligatorio.
